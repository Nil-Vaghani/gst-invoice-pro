🚀 QUICK START (First Time Setup):
──────────────────────────────────────────────────────────────────

1. Read SETUP.md (5 min)
2. cp .env.example .env
3. Edit .env with your MongoDB connection & settings
4. cd backend && npm install && npm run dev
5. cd ../frontend && npm install && npm run dev
6. Open http://localhost:5173

⏱️  Total Time: ~10 minutes

📝 KEY ENVIRONMENT VARIABLES:
──────────────────────────────────────────────────────────────────

Backend (.env):
  MONGODB_URI             → Database connection string
  PORT                    → Server port (default: 5001)
  JWT_SECRET              → Token signing key

Frontend (.env):
  VITE_API_BASE_URL       → Backend API URL
  VITE_FIREBASE_*         → Firebase credentials

──────────────────────────────────────────────────────────────────

🌐 API ENDPOINTS:
──────────────────────────────────────────────────────────────────

Authentication:
  POST /api/auth/signup            → Register user
  POST /api/auth/login             → Login user

Invoices (require JWT token):
  GET  /api/invoices               → Get all invoices
  POST /api/invoices               → Create invoice
  GET  /api/invoices/:id           → Get one invoice
  PUT  /api/invoices/:id           → Update invoice
  DELETE /api/invoices/:id         → Delete invoice

Health:
  GET  /                           → Health check

Full docs: See API.md

🛠️  TROUBLESHOOTING QUICK FIXES:
──────────────────────────────────────────────────────────────────

MongoDB won't connect:
  → Check MONGODB_URI in .env
  → Verify IP is whitelisted in Atlas

Port already in use:
  → Change PORT in .env
  → Or kill existing process

Dependencies missing:
  → rm -rf node_modules package-lock.json
  → npm install

Blank page on load:
  → Check browser console (F12)
  → Make sure backend is running
  → Verify VITE_API_BASE_URL

More help: See README.md → Troubleshooting section
